# Reports and output

## Generated reports

| Report | Contents |
|---|---|
| Cover sheet and table of contents | Project details and every page with its latest revision |
| Panel schedules | Breakers by slot with load and voltage drop |
| Bill of materials | Parts grouped by part number with prices |
| Terminal diagrams and connection list | Terminals and every connection |
| Cable overview and diagrams | Cables and their conductors |
| Tubing list | Tubes grouped by outside diameter |
| Door and window schedule | Every door and window on the floor plans |
| Framing reports | Lumber lists, cut lists, cutting plans and building views |
| Deck hardware lists | Hangers, brackets, fasteners and concrete per deck |
| Tile reports | Tile cut lists and tile orders |
| Revision overview | Revisions and the pages changed in each |

- Project properties turn each report on or off and set the order of the reports and of the page tree sections.

## Custom reports

- A custom report is an editable copy of a report, with filters, hidden and renamed columns, extra rows and notes.

## Parts

- Part numbers are the manufacturer code and the order number, for example PXC.3031212.
- The manufacturer list is shared by everyone on the server.

## Export and import

| Format | Use |
|---|---|
| PDF | Vector pages with bookmarks and clickable cross-references |
| Excel | Bill of materials, framing materials, tile layouts; Excel import updates devices by ID |
| CSV | Bill of materials, panel schedule, terminals; parts import |
| DXF, SVG, PNG | Floor plan levels and pages |
