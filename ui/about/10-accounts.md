# Accounts and sharing

## Sign-in

- Accounts have a user name and a password. Anyone who can reach the server can create one unless sign-up is turned off.
- Change password signs out the other devices.

## Projects

- Projects are kept on the server. File > Open lists your projects and the ones shared with you.
- A project is shared as view only or editable. Only the owner shares or deletes it.
- Projects are imported from an `.osp` file and downloaded as one.

## Editing

| Situation | Behavior |
|---|---|
| Someone else is editing | The project opens read-only and names the editor |
| A save would replace a newer save | You choose to replace their changes or save a copy |
| A read-only project is changed | It can be saved as your own copy |
| Unsaved work | Kept on the server every 30 seconds and offered back at the next sign-in |

## Shared and personal data

| Data | Kept |
|---|---|
| Preferences, workspaces, ribbon | Per user |
| Symbol and macro library, parts, manufacturers, blocks | Shared by everyone on the server |

## Storage

- Everything is in the data folder. Back it up by copying the folder.
